# Specs

Specs de funcionalidades, criadas com o [Spec Kit](https://github.com/github/spec-kit) (`/speckit-specify`). Cada funcionalidade fica em `specs/NNN-nome/` com `spec.md`, `plan.md` e `tasks.md`.

Veja o fluxo em [docs/desenvolvimento.md](../docs/desenvolvimento.md#fluxo-de-trabalho) e os princípios na [constituição](../.specify/memory/constitution.md).
