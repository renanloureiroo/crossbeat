# protocol/

Fonte da verdade do serviço GATT do Crossbeat, compartilhada entre `wear/` e `ios/`.

- `proto/crossbeat/v1/`: mensagens protobuf (rascunho)
- Framing, UUIDs e regras de versionamento: [docs/protocolo.md](../docs/protocolo.md)

O código gerado vai para `protocol/gen/` e não é versionado.
